# Sky Jump

**Sky Jump** is a lightweight 3D platformer game designed for GitHub Pages. Players navigate through floating islands in the sky, collecting stars while avoiding deadly gaps.

## Play URL

After this repo is deployed with GitHub Pages, the game is playable at:

- `https://jasonycw.github.io/games/sky-jump/`

## How to Play

### Objective

- Collect stars by jumping between sky islands.
- Each new island reached gives you a star and 10 points.
- Progress to the next level after collecting 5 stars.

### Controls

- **Move:** `W A S D` to walk on platforms.
- **Jump:** `Space` to leap between islands.

### Gameplay Features

- Progressively wider platform layouts
- Deadly gaps that reset the run if you miss a landing
- Star scoring based on reaching new islands

## Technical Notes

- Built with pure HTML/CSS/JS and ES modules
- Uses Three.js from CDN for 3D rendering
- All assets and levels are preloaded for instant play
- Fully responsive design for desktop and mobile
