# CS DM asset conventions

All assets in this folder must be original, generated, or intentionally omitted until later tasks add them. Do not copy Counter-Strike content or hotlink remote media.

## Folder map
- `textures/` - generated or placeholder texture art
- `icons/` - generated UI/icon art
- `models/` - placeholder model definitions or notes for future 3D assets
- `sounds/` - generated or placeholder audio assets; T28 currently generates feedback at runtime from Web Audio oscillator/noise envelopes in `src/audio/` instead of shipping copied clips
- `screenshots/` - documented omissions for now; final gameplay captures belong under `/games/cs-dm/screenshots/`

## Current status
- Placeholder assets only.
- Relative paths only.
- No remote URLs.
