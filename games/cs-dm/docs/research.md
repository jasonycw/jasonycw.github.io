# CS DM research dossier

## Fidelity targets
- Map feel should track Dust2-style route topology: long A, catwalk, mid doors, lower tunnels, upper tunnels, A split, B split, and clear choke points.
- Gameplay should aim for CS 1.6 gun names, buy flow, recoil feel, movement timing, and round pacing rather than a generic arena shooter.
- HUD should stay familiar: health, armor, ammo, team score, round timer, money/buy state, and readable combat feedback.
- Bot navigation should use waypoint graphs that cover spawns, chokepoints, bombsite entries, retake paths, and fallback patrol loops.
- P2P should be manual-code WebRTC, best-effort, NAT/firewall dependent, and use no hosted signaling service.

## IP-safety constraints
- This project is not affiliated with Valve, Counter-Strike, or Steam.
- Use original assets only: custom textures, models, sounds, icons, UI, and screenshots.
- Do not copy Counter-Strike binary assets, textures, sounds, sprites, icons, screenshots, maps, BSPs, or exported meshes.
- Public-repo visibility increases IP risk, so keep provenance notes with every asset bundle and never hotlink remote media.
